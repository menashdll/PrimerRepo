# Cuadratura Gaussiana

## Introduccion

En este proyecto se busca aproximar numnericamente el valor de una integral

por medio del metodo de cuadratura de Gauss-Legendre

La implementacion del metodo se ha realizado en python. Este emplea distintas cantidades de puntos de evaluacion hasta converger a una tolerancia especifica.

Ademas, se usa el calculo de la siguiente integral a modo de ejemplo

$I = \int_1^3 \left(x^6 - x^2\sin(2x)\right)\,dx$$

Esta documentación contiene una explicación del método numérico,
un ejemplo de uso del programa y la referencia de las funciones
implementadas.
